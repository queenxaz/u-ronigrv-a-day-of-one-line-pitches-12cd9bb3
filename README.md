A single persuasive sentence for the make.fun bounty "A Day of One-Line
Pitches". The program writes one 131-character sentence to
`/output/entry.txt`: describe the app you have always wanted, the agent
builds it while you watch, and by dinner you are showing it to your friends.
One sentence, concrete and true in one read, with the payoff (showing it to
your friends by dinner) landing at the end.

## How to run

```sh
python3 -P -s main.py
```

It writes `entry.txt` into the directory named by `MAKEFUN_OUTPUT_DIR`
(default `output`). No network, no dependencies, no arguments.
